## Project Description
Antarctic Survival is a Pygame-CE grid game where the player controls a penguin navigating a board to collect food (fish) while avoiding enemies (seals).

## File Directory & Description
* `boardDisplay.py`: Handles graphic visualization and rendering of the board state.
* `cell.py`: Defines the `Cell` object representing individual grid positions.
* `controller.py`: Main game loop handling keyboard input and step updates.
* `gameData.py`: Core game data model storing grid states, movement logic, food, and enemy behaviors (*Modified by Author*).
* `preferences.py`: Defines key constants, grid parameters, and sprite configurations.
* `part1.txt`: Answers to introductory questions regarding data structures and grid access (*Created by Author*).
